# 水印工坊 v1.0.6 — 发布说明

> 安装包见 Assets：`shuiyin-gongfang-v1.0.6.apk`（arm64-v8a / Android 8.0+ / versionCode 6）

**这一版，我们把「内容版图」又往外推了一大圈。**

它曾经擅长视频，后来学会了图文与实况；这一次，小红书、微博、微信公众号正式入列——连同一次贯穿全平台的稳定性打磨。

## 新朋友

**小红书** —— 视频、图文、图集、实况图，一次拿全。实况图的「动」与「静」同名配对，落进相册就是一张会动的照片。首次解析需在应用内登录一次，之后一路畅通；代价也说在前面：小红书限制同时在线设备，应用内登录会把电脑网页版挤下线。

**微博** —— 视频、图文、图集、实况图、动图、音频、头条文章，悉数到场。无需登录、无需 Cookie；音频终于有了进度条与暂停键。文章里的图片是冷加载的，应用会完整读完正文再动手，因此这类链接会多等两三秒——慢一点，但一张不落。

**微信公众号 / 图文贴图** —— 标题、作者、正文图片、文章内视频（自动择最高清）一并取出；贴图优先「查看原图」。正文默认折四行，可展开、可收起、可一键复制。全程不碰登录。

**微信视频号** —— 能认出它、看懂它（标题、作者、封面），但它的视频被微信客户端牢牢锁住，服务端不下发地址。我们选择如实告知，而不是给一个虚假的「下载成功」。

## 一块新地基：一机一码

三次免费体验，之后一钥一机。换机不必重买，由开发者解绑即可。首次激活需要联网（授权服务在境外，设置页备好了加速器入口）；激活之后，日常使用不再被网络牵着走。

## 打磨与修复

- **抖音**：补齐接口公共参数，治好了「部分视频解析不出」与「结果与链接对不上」的老毛病；橱窗挂载视频不再被推荐流顶包，拿不到就如实报错。
- **抖音**：平台改版后图文作品一度被误判成视频——黑屏、有声、零秒、下到一段 BGM。现已按图片与实况的真实结构重新识别；拿不到动效地址时自动回退浏览器链路，单张实况与实况合集都回到正轨。
- **小红书**：修掉相册里的 0×0 与参数失踪——图片按真实格式落盘，再转成真 JPEG，机型、ISO、镜头一并留下。
- **微博**：修复图片 403、音频无进度条；正文类链接改走内置浏览器，长视频藏在正文里也能被找出来；部分实况图合集曾被误判成「音视频分轨」，现已恢复正常的预览与下载。
- **公众号**：修掉「图文 + 视频」文章里视频偶尔预览失败的问题——视频直链短时有效，且 CDN 会校验请求身份，现已在播放与下载前分别补齐。
- **下载**：抖音 / 小红书 / X 的直链改为分块并行，进度与速度显示更接近真实体感。
