# 🎬 水印工坊 v1.0.6 —— 内容版图又往外推了一大圈

> 安装包见下方 Assets：`shuiyin-gongfang-v1.0.6.apk`

它曾经擅长视频，后来学会了图文与实况；这一次，**小红书、微博、微信公众号**正式入列，连同一次贯穿全平台的稳定性打磨。

## ✨ 新增

**🌱 小红书** —— 视频、图文、图集、实况图一次拿全，实况图的「动」与「静」同名配对，落进相册就是一张会动的照片。首次解析需在应用内登录一次，之后不必再导出 Cookie；代价写在前面：小红书限制同时在线设备，应用内登录会把电脑网页版挤下线。图片保存后保留拍摄参数（机型、ISO、镜头等），相册里的分辨率也正常。

**🌊 微博** —— 视频、图文、图集、实况图、动图、音频、头条文章悉数到场，无需登录、无需 Cookie，音频终于有了进度条、暂停键与时长。正文类链接改走内置浏览器，藏在正文里的长视频也能被找出来，部分实况图合集曾被误判成「音视频分轨」，现已恢复正常。文章里的图片是冷加载的，应用会完整读完正文再动手，所以这类链接会多等两三秒——慢一点，但一张不落。

**📮 微信公众号 / 图文贴图** —— 标题、作者、正文图片、文章内视频（自动择最高清）一并取出，贴图优先「查看原图」。正文默认折四行，可展开、可收起、可一键复制；全程不碰登录。

**📺 微信视频号** —— 能认出它、看懂它（标题、作者、封面），但视频被微信客户端牢牢锁住，服务端不下发地址。我们选择如实告知，而不是给一个虚假的「下载成功」。

**🔐 一机一码授权** —— 未激活可免费解析 3 次，之后一钥一机；换机不必重买，由开发者解绑即可。首次激活需要联网（授权服务在境外，设置页备好了加速器入口），激活之后日常使用不再被网络牵着走。

## 🔧 修复

- **抖音解析不出、结果对不上**：补齐接口公共参数；橱窗挂载视频不再被推荐流顶包，拿不到就如实报错。
- **抖音图文被误判成视频**：平台发放规则改版后，图文作品一度黑屏、有声、零秒，下到一段 BGM。现已按图片与实况的真实结构重新识别；拿不到动效地址时自动回退浏览器链路，单张实况与实况合集都回到正轨。
- **小红书图片分辨率显示 0×0、拍摄参数丢失**：图片按真实格式落盘，再转成真 JPEG，相册里分辨率正常，机型、ISO、镜头等拍摄参数也一并保留。
- **微博图片 403、音频没有进度条**：补齐防盗链请求头；音频补上进度、暂停与时长。
- **公众号「图文 + 视频」预览失败**：视频直链短时有效，且 CDN 会校验请求身份，现已在播放与下载前分别补齐。
- **报错不再含糊**：私密作品、已删除作品、随手打的字、网络不通，分别给出可读的原因与排查方向。

## 💡 改进

- **下载更快**：抖音 / 小红书 / X 的直链改为分块并行，进度与速度显示更接近真实体感。
- **正文可读可带走**：公众号正文支持展开 / 收起 / 一键复制，标题与正文分开呈现。
- **平台识别更诚实**：微信视频号单独成栏，不再混进公众号；预览态明确标注「不支持直接下载」。

## ⚠️ 已知限制

- 快手尚未入列，仍在待办清单上。
- 跨平台正文展示目前只在微信公众号提供，微博 / 小红书 / 抖音 / X 后续跟进。
- 微信视频号的视频无法下载，这不是解析问题，是微信不下发地址。
- 微博 `t.cn` 短链与 `wbox` 卡片页暂不支持。
