# 🎬 水印工坊 v1.0.8 —— 包更小、名字更体面、实况真的会动

> 安装包见下方 Assets：`水印工坊-1.0.8.apk`

这一版没有新平台，重点是把几个每天都在用、却一直将就的细节做对：安装包小了三分之一，下载文件名从作品编号改成「标题 - 作者」，公众号图文里的实况图也终于能动了。

## 💡 改进

**📦 安装包从 41.2MB 降到 27.8MB** —— 开启 release 的 R8 代码压缩与资源裁剪，把没用到的类、代码和资源从包里删掉；没有替换图标、没有删功能。代码部分从 14.41 MiB 压到 2.04 MiB，安装包整体减少 32.6%。

**📝 下载文件名改成「标题 - 作者」** —— 以前末尾挂的是作品编号（`标题 [7692598123456789012].mp4`），对归档没有意义。现在：

- 标题优先，作者最多占可用长度的三分之一；
- 标题太长时先丢掉末尾话题标签，再裁剪并补省略号；
- 重名自动另存 ` (1)`、` (2)`；
- 作者缺失时显示「未知作者」；
- 安卓与 Windows 同一套规则，正常下载、直链下载、图集下载都一致。

**⚙️ 内置解析引擎升级到 yt-dlp 2026.11.23** —— Windows 与安卓统一版本并锁定，构建不会再悄悄换版本。YouTube、X 等站点的近期变化随之修好。

**🔐 授权后台** —— 管理页重做：列表分页、搜索筛选、备注编辑、操作审计。激活时会记录设备品牌、型号与 Android 系统版本，用于更好地定位、排查并修复用户反馈的问题。

## 🔧 修复

**🖼 公众号实况图只剩一张静态图** —— 微信「图片消息」里的每张图都带着 2~3 秒的动效视频，旧实现只读了静态图。现在会解析全部清晰度档位并取最高清的一条；只要有一张带实况，整条就按「实况图」展示，滑到哪张哪张叠播动效；下载时图片与动效同名配对（`01.jpg` + `01.mp4`），播放与下载的 CDN 鉴权也已补齐。

**🏷 实况图导出名变成一串编号** —— 部分机型（vivo 实测）相册返回的是内部编号，导出后叫 `1000679998_实况_….jpg`。现在会回查真实文件名，拿不到才用「实况」兜底。

## ✨ 新增

**📋 历史记录：作者、账号 ID、原始链接都能单独复制** —— 以前展开后只能看不能拿。现在三行各有复制按钮；值为空时整行隐藏；链接仍可展开全文；所有平台通用，Windows 网页端同步。

**📐 X / 小红书显示真实画质** —— 不再固定写「原始画质」。X 单视频显示 `宽×高`，多视频逐条列出，纯图片只报张数；小红书显示选中那条视频的真实分辨率，没有音轨会标注「该条只有画面，无音轨」。

## ⚠️ 已知限制

- 公众号实况图本次覆盖「图片消息」模板，普通长文章正文里的实况图暂未覆盖；
- 微博正文页、微信视频号的部分场景拿不到分辨率，仍显示原文案，不编造数字；
- 实况图存成「同名图片 + 视频」两个文件，能否被系统相册识别为动态照片取决于机型；
- 作者信息缺失时显示「未知作者」。
