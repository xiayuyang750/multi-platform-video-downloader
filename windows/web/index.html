关于

支持范围：YouTube / B站 / 抖音 / 快手 / TikTok / X / Instagram / 小红书 / 微博 / 微信公众号 / 微信视频号（仅预览）。抖音、快手、小红书、微博的图文、图集、实况图都已支持； 实况图会存成「图片 + 同名视频」两个文件。

其他平台的解析与下载由内置 yt-dlp 完成；音视频合流与 MD5 改写用 ffmpeg。 抖音走公开接口（浏览器仅兜底），快手走移动版分享页，公众号是公开网页； 小红书走浏览器模式（首次登录一次），微博正文页走移动版页面；X 优先用第三方服务。

清晰度、编码与体积：同样标着 1080p，体积可能差出一倍 —— 差的是编码与码率，不是分辨率。H.264 兼容性最好、体积偏大；H.265 同画质体积小得多， 但部分老设备解不了；AV1 体积更小、能放的设备更少。拿不准就选 H.264 那一档。

MD5：整份文件的指纹。改的是容器里的元数据，不动画面 —— 视频往 mp4 的 comment 里写随机串，图片写进 PNG 的 tEXt 或 JPEG 的 COM 段， 音视频一个字节都没有重编码，画质零损失。改完前后体积只差几十字节是对的， 操作在「MD5」页签，全程另存副本。
